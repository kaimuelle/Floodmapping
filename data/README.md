Processing notes: To use the data like I did, you have to download the images that are used in the notebook and put them into the respective data folder. I also renamed the files to make it more organized.

In order to do this automatically you can use the python script "filetransfer_renaming" in the script folder. For it to work you need to have downloaded the files already into your "downloads" folder. Also you need the project structure as it is in the GitHub. The script then takes the files, puts them into their respective data folder and renames then. 
The script is fully done by AI. If it does not work then creating your own script is most likely the fastest way.
